Sistema de presentaciones

Un link, y se ve.

Esta página es la prueba de que el carril funciona: HTML estático servido desde internet, sin cuenta, sin instalar nada, sin video.

Cómo se usa

1 · Se armaLa presentación se escribe como una carpeta con un index.html.
2 · Se publicapublicar <nombre> la sube y devuelve el link.
3 · Se envíaEl link se comparte por WhatsApp o correo. Se abre en cualquier navegador.

Qué entra y qué no

Entra: texto, diagramas, imágenes, planos, tablas, audio corto.

No entra: video, datos personales, credenciales. Un guardián revisa cada archivo antes de subir y aborta si encuentra rutas del equipo, correos o tokens.

Para la vista

Flechas ← → para navegar. Ctrl+P imprime una hoja por diapositiva, así también sirve en papel.
